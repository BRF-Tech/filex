# ShareX

ShareX is set up through **Uploaders** since 0.60: make an uploader in
**Account settings → Uploaders**, click **Download ShareX settings (.sxcu)**
and double-click the file. One uploader serves images, text and files, with
its own key, folder, link rule and a deletion link per upload.

→ [Uploaders](UPLOADERS.md) · [ShareX](UPLOADERS.md#sharex) ·
[moving from the ShareX endpoint](UPLOADERS.md#moving-from-the-sharex-endpoint)

The old endpoint, `POST /api/sharex/upload` with an API key, still answers
and is removed in the next major release.
